# Portfólio — Gabriel Voidaleski

Portfólio profissional de Gabriel Voidaleski, Desenvolvedor Full Stack. O site apresenta experiência profissional, projetos (Appunture, FlyHigh e MaintenanceApp), competências técnicas, formação e canais de contato.

## Stack

- Angular 19 com componentes standalone
- TypeScript
- CSS responsivo sem framework visual
- Renderização no servidor e prerenderização via Angular SSR

## Desenvolvimento local

```bash
npm ci
npm start
```

O servidor de desenvolvimento fica disponível em `http://localhost:4200`.

## Validação

```bash
npm test -- --watch=false --browsers=ChromeHeadless
npm run build
```

## Conteúdo

O conteúdo em português e inglês é baseado nos currículos atualizados de Gabriel. O seletor de idioma no cabeçalho alterna o conteúdo, os metadados e o PDF para download. Os arquivos estão em `src/assets/curriculum-gabriel-voidaleski-pt.pdf` e `src/assets/curriculum-gabriel-voidaleski-en.pdf`.

A experiência no Banco do Brasil está organizada em desenvolvimento full stack, inteligência artificial, dados e analytics, e sustentação e infraestrutura. A seção de projetos precede as competências técnicas, que distinguem a experiência corporativa das tecnologias utilizadas nos projetos acadêmicos. O Appunture inclui um link para seu repositório público.
